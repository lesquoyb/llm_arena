# Corpus commun — protocole 1

- rules.md : règles, ressources, carte, équipes et préparation.
- api-guide.md : fonctions des stratégies de contrôle, paramètres et erreurs.
- syntax.md : syntaxe minimale, includes, état et communication.
- ../authoring.md : exemple complet et contrat de soumission.
- ../leekscript-v1/api.md : toutes les signatures et coûts déclarés.
- ../leekscript-v1/{weapons,chips,summons,components}.json : équipements figés.

Depuis read_docs, les chemins commencent par corpus/ ou leekscript-v1/.
Ce corpus est figé par hash pour chaque expérience. Les comportements non
documentés ne doivent pas être inventés ; consulter le code officiel au
commit b99a174dd938260d9e47b2e65a208cb32230e26e pour lever une ambiguïté
lors de la préparation du corpus, pas pendant une session expérimentale.
