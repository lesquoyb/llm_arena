## Creating a function

We have already used several standard functions (setWeapon, moveToward, etc.). You can also create your own **custom functions**, with the following syntax:
```
function sum(x, y) {
	return x + y
}
```
- The `function` keyword
- The name of the function: `sum`
- The list of the function's parameters, in parentheses `(` `x, y` `)`
- The block of instructions, in braces `{` `x + y` `}`

The `return` keyword, which is optional, makes the function return a value. In the previous example, the function takes the parameters `x` and `y` and returns their sum: `x + y`.
