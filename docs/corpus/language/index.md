Topic chapters come from the English Leek Wars encyclopedia. Website widgets,
quizzes and complete AI listings are omitted; syntax explanations are retained.
Tutorial snippets can be incomplete or depend on earlier variables; check function
availability in the pinned API rather than assuming every illustration compiles alone.

Arena runs version 4 with fixed compiler settings. Online editor configuration
instructions do not change those settings. Include only your own submitted files;
registers start empty per fight. The adapted cheat sheet explains these differences.
Game rules, scenario constraints, player equipment and API signatures are separate:
use corpus/rules.md, the scenario briefing and leekscript-v1/api.md.
